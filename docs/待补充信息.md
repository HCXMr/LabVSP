## 数据与研究说明

- [ ] 逐图复审标注，优先查看 `reports/instance_overlaps.csv` 中的 7 张多物体图像及 8 对边界重叠。
- [ ] 判断未知区域是否需要补标；原有 `255` 已保留，不自动当作背景。
- [ ] 如论文需要实物尺寸，补测 `metadata/objects.json` 的空值，记录单位、方法和次数；无需此项时在正文说明缺失。
- [ ] 补充相机型号、采集布置、光照、背景、视角和标注流程的正式描述；已有相机内参与原时间戳不替代这些说明。
- [ ] 说明深度单位的核验方式及透明物体原始深度的缺失与错误，不将其描述为独立表面真值。
- [ ] 论文中明确 `test` 是开发留出集，`multi_test` 是已见实物新布局；新增盲测数据应另建版本和清单。
- [ ] `handle` 在标签字典中保留但没有正像素；不能写成“9 类均有训练样本”。

## 版本管理

作者、引用等文档更新应记录变更，并在新发布中重建对应压缩包。修订标签、增添图片或改变划分时，应保留旧版本，记录增删样本与修改原因，重新生成校验和、检查报告和压缩包。不要把旧论文结果直接绑定到修改后的数据版本。

数据许可证从首个公开版本起为 CC BY-NC 4.0。任何后续许可说明都不能假装撤回已经依法授出的使用权限；需要变更时应明确适用的版本和权利范围。
